# AppForge Studio

نسخه اولیه محیط شخصی طراحی و ساخت اپلیکیشن اندروید.

## وضعیت فعلی
- پوسته واکنش‌گرا و مناسب موبایل
- داشبورد فارسی راست‌چین
- معرفی بخش‌های اصلی استودیو
- پیش‌نمایش نمایشی بوم و پنل ویژگی‌ها

## مسیر توسعه
1. بوم طراحی تعاملی و انتخاب/جابجایی اجزا
2. کتابخانه اجزای قابل گسترش
3. ویرایشگر ویژگی‌ها و سیستم ذخیره پروژه
4. منطق بصری رویدادها و اتصال‌ها
5. تولید پروژه و فرایند ساخت APK

> این نسخه هنوز خروجی APK یا ویرایشگر واقعی ندارد؛ موارد بالا مراحل توسعه‌اند.
